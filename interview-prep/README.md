# Interview Prep

Папка для підготовок до тех-співбесід під конкретні вакансії.

## Як користуватись

У чаті з агентом встав **посилання на вакансію (Djinni)** і напиши щось на кшталт:

> Підготуй мене до співбесіди і основних питань враховуючи мій досвід
>
> https://djinni.co/jobs/......

Агент:
1. прочитає мій досвід із `.cursor/skills/rewrite-cv/experience.md`,
2. витягне вакансію (через Djinni MCP `get_job`, або WebFetch, або попросить вставити текст),
3. зіставить вимоги з моїм реальним досвідом (fit-матриця),
4. згенерує файл `interview-prep/<компанія-або-роль>-<дата>.md` з ймовірними питаннями, готовими відповідями (STAR + реальні факти), прогалинами і питаннями роботодавцю.

Якщо вакансія без посилання — просто встав її текст разом із проханням.

## Правила
- Відповіді будуються лише на підтверджених фактах (без вигадок).
- NDA-формулювання — з `local/profile.env` / experience.md.
- Кожна підготовка = окремий файл у цій папці.

Деталі процесу — у скілі `.cursor/skills/interview-prep/SKILL.md`.
