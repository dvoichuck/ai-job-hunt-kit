# boards/

Registry of job boards the agent can search. Account logins live in
`accounts.md` (gitignored). Copy `accounts.example.md` first.

- `registry.md` — platforms and how the agent reaches them
- `searches.md` — query list (edit for your track)
- `accounts.md` — connected / missing (no passwords)

Vacancies go to `applications/tracker.md`. Apply only after a dry run and your OK.
